# Jean César Advogado & Associados

Site institucional de alto padrão do **Dr. Jean César Rodrigues dos Santos** (OAB/MG 213.482), Presidente da Comissão de Direito Imobiliário da 145ª Subseção da OAB/MG, com escritório sediado na R. Pereira Guimarães, 180 - 1° ANDAR - Centro, Mateus Leme - MG, com atendimento presencial e on-line para todo o Brasil.

## Desenvolvimento

Instale as dependências com `npm install` e inicie o ambiente local com `npm run dev`.

Abra [http://localhost:3000](http://localhost:3000) para visualizar o site.

## Tecnologias

- Next.js 16 com App Router e Turbopack
- React 19
- Tailwind CSS 4
- Framer Motion
- Lucide React
